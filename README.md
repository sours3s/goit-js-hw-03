# goit-js-hw-03

Домашнє завдання: три незалежні задачі на роботу з масивами — перетворення рядка, об'єднання масивів і фільтрація за умовою.

## Завдання

- **task-1.js** — `slugify(title)` перетворює заголовок статті на slug (нижній регістр, слова через тире).
- **task-2.js** — `makeArray(firstArray, secondArray, maxLength)` об'єднує два масиви й обрізає результат до `maxLength`.
- **task-3.js** — `filterArray(numbers, value)` повертає новий масив із чисел, більших за `value`.

## Перевірка

Відкрий `index.html` і подивись результати виклику функцій у консолі браузера.
